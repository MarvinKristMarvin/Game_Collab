
CAHIER DES CHARGES

Présentation du projet : 
 Game Hearts est une application de rencontre entre les personnes travaillant dans le secteur du jeu video, afin de former
des equipes. Les utilisateurs peuvent s'inscrire et creer un profil pour se rendre disponible au recrutement, mais aussi découvrir tous les profils et les contacter.
Il est possible d'utiliser des filtres de recherche (métiers, age, langues etc) afin de trouver des collaborateurs adaptés à son projet.

Besoins et objectifs : 
 Souvent, les développeurs sont contraints de créer des jeux seuls, car ils ne trouvent personne avec qui travailler. Avec Game Hearts,
il sera possible de se regrouper autour de projets de jeux vidéos, afin de créer des jeux vidéos de meilleur qualité, plus rapidement et en groupe.
Game Hearts doit simplifier la recherche de collaborateurs au maximum.

Cible : 
 L'application cible tous les acteurs du jeu vidéo (developpeur, artiste, animateur, modeliste, musicien, sound designer, compositeur, etc...)

Charte graphique :
- description : l'application doit rappeler le secteur du jeu vidéo -> couleurs contrastées, thème principal sombre. Interface épurée et rapide à comprendre.
- couleurs : rouge #F1005C, violet #BB0072, jaune #FFD840, orange #FF9900, noir rougeâtre #0A0808
- fonts : Noto Sans
- drapeaux : https://flagpedia.net/download/icons

Minimum viable product : 
 permettre aux utilisateurs de trouver des profils qui correspondent au besoins de leur projet de jeu vidéo grâce à des filtres de recherche.

Améliorations futures possibles :
- Recherche par mots clés (cherchant dans la description des profils)
- Chat direct dans l'application à la place du mail
- Ajout d'images ou autres documents dans le profil
- Acces à un profil détaillé
- Possibilité de créer des présentations de projets, sur lesquels les utilisateurs peuvent swiper et demander de participer
(Au lieu de contacter par mail, cela pourrait devenir une invitation à participer au projet, si le profil accepte, alors les participants au projet peuvent chatter ensemble)
- Ajout d'un systeme d'abonnement premium (pour avoir plus de visibilité par exemple)

Technologies :
- React : Simplifie la création et la gestion des composants, favorise leur réutilisabilité et garantit la scalabilité si l'application se développe.
- Vite : Bundler et transpileur rapide, optimisé pour le développement moderne. Il permet une meilleure expérience développeur grâce au hot module replacement (HMR) performant.
- Sass : Superset de CSS qui permet l'indentation, l'utilisation de variables, de mixins, et de fonctionnalités avancées pour une meilleure gestion des styles.
- Axios : Simplifie les requêtes HTTP vers le backend, avec une API claire, support des promesses et gestion des erreurs facile.
- Cypress : Framework de tests end-to-end moderne, rapide et fiable, utilisé pour valider le comportement complet de l'application en interaction utilisateur.
- Jest : Bibliothèque pour créer et exécuter des tests unitaires et d'intégration, avec un support natif de TypeScript et une configuration flexible.
- Express : Framework backend léger et simple à configurer, permet de gérer facilement les routes, les requêtes HTTP, et de construire des API.
- TypeScript : Améliore la fiabilité grâce au typage statique, facilite la maintenance du code et réduit les erreurs dès le développement.
- Node.js : Environnement JavaScript côté serveur léger et performant, permettant un développement unifié entre frontend et backend.
- Nodemon : Accélère le développement backend en redémarrant automatiquement le serveur lors des modifications du code.
- Cors : Middleware qui permet de configurer les autorisations d'accès au backend pour certaines URL, améliorant la sécurité.
- Bcrypt : Bibliothèque pour hacher et sécuriser les mots de passe avant de les stocker dans la base de données.
- Csurf : Middleware pour protéger les applications contre les attaques CSRF (Cross-Site Request Forgery), garantissant une meilleure sécurité.
- Validator : Bibliothèque de validation des données, utile pour vérifier et nettoyer les entrées utilisateur (exemple : validation d'email, de mots de passe).
- Jsonwebtoken (JWT) : Permet de générer et vérifier des jetons JWT pour l'authentification sécurisée des utilisateurs et la gestion des sessions.
- PostgreSQL : Base de données relationnelle puissante et open source, idéale pour stocker, organiser et interroger les données utilisateur. Elle est fiable, performante et propose des fonctionnalités avancées (comme les transactions et les types personnalisés), tout en restant adaptée aux petits et grands projets.

Routes :
- /homepage -> accueil et explications de l'app
- /search -> page de présentations des profils trouvés selon des critères de recherche
- /profile -> connexion et inscription, si connecté montre sa page de modification de profil
- /contact -> informations de contact du site
- /privacypolicy -> rgpd et mentions légales
- /404 -> page 404

API :
- GET /test -> Tester la connexion au backend
- GET /api/users/filtered?name=xxx&age=xxx,xxx&language=xxx,xxx&jobs=xxx,xxx&keywords=xxx,xxx&remuneration=xxx,xxx -> Recherche des profils en utilisant des filtres
- PATCH /api/user/:id -> Modifier son profil
- DELETE /api/user/:id -> Supprimer son profil
- POST /signup -> Créer son profil
- POST /login -> Se connecter
- POST /logout -> Se déconnecter

Dictionnaire de données :
Table utilisateur
- id INTEGER PK NOT NULL identifiant de l'utilisateur
- password TEXT NOT NULL mot de pass de l'utilisateur
- mail TEXT UNIQUE NOT NULL email d'inscription de l'utilisateur
- name TEXT NOT NULL nom de l'utilisateur
- age INTEGER NOT NULL age de l'utilisateur
- available BOOLEAN NOT NULL disponibilité de l'utilisateur pour être recruté
- description TEXT NOT NULL description des compétences de l'utilisateur
- portfolio_url TEXT url du portfolio de l'utilisateur
- profile_mail TEXT NOT NULL adresse email de contact
- created_at DATE NOT NULL date de création de l'utilisateur
- updated_ at DATE date de modification du profil de l'utilisateur
- role ENTITY NOT NULL role de l'utilisateur (id_role)
Table role
- id INTEGER PK NOT NULL identifiant du role
- name TEXT NOT NULL nom du role
Table job
- id INTEGER PK NOT NULL identifiant du job
- name TEXT NOT NULL nom du job
Table language
- id INTEGER PK NOT NULL identifiant du language
- name TEXT NOT NULL nom du language
Table remuneration
- id INTEGER PK NOT NULL identifiant du type de remuneration
- type TEXT NOT NULL type de remuneration

Autres points à respecter :
- Sécurité : authentification sécurisée, protection contre les failles courantes (XSS, injections SQL, etc.), CORS.
- Déploiement : rédaction a minima d'une procédure de déploiement (CI/CD en bonus).
- Responsive : application développée en mobile first et responsive.
- Accessibilité : respect des normes d'accessibilité web WCAG AA. (https://webaim.org/standards/wcag/checklist)
- RGPD et mentions légales : mettre en place les mentions légales liées au règlement général sur la protection des données (RGPD).
- Versionning : utilisation de Git et GitHub.
- API : en consommer au moins une (qu’elle soit interne ou externe). Un seul appel peut être suffisant, l’API ne doit pas forcément être utilisée pour tout le projet.
- SEO : appliquer les bonnes pratiques visant à maximiser le référencement du projet.
- Tests : plan de tests couvrant les fonctionnalités principales du projet.
- Conteneurisation (Docker) : pour l'environnement de développement voire pour le déploiement
- Démarche d'éco-conception (optimisation des images, minification des fichiers, etc.).
